# Bluetooth Controlled Car Using ARM7 LPC2129
Bluetooth Controlled Robotic Vehicle using ARM7 LPC2129, HC-05 Bluetooth Module, UART Communication and L293D Motor Driver.

## Technologies Used
- ARM7 LPC2129
- HC-05 Bluetooth Module
- L293D Motor Driver
- Embedded C
- UART Communication

## Project Description
Developed a Bluetooth-controlled robotic vehicle using ARM7 LPC2129. The system receives commands from a smartphone through the HC-05 Bluetooth module and controls DC motor movement using the L293D motor driver. UART communication was implemented for wireless command transmission and real-time vehicle control.

## Features
- Forward, Reverse, Left, Right and Stop control
- UART-based Bluetooth communication
- Real-time motor control
- Embedded C firmware development

## Skills Demonstrated
- Embedded C
- ARM7 LPC2129
- UART Protocol
- Hardware Interfacing
- Firmware Development
- Hardware Debugging
